# 🚗 DADDY AUTO

Site web de vente de voitures de luxe et de sport.

## 📋 Description

DADDY AUTO est un site vitrine élégant pour la présentation et la vente de véhicules haut de gamme. Le site offre une expérience utilisateur fluide avec un design moderne et responsive.

## ✨ Fonctionnalités

- 🏠 **Page d'accueil/Connexion** : Interface de connexion utilisateur
- 🚘 **Page Produits** : Catalogue de véhicules avec descriptions détaillées
- 📞 **Page Contact** : Formulaire de contact et coordonnées
- 📱 **Design Responsive** : Optimisé pour mobile, tablette et desktop
- 💬 **Intégration WhatsApp** : Contact direct via WhatsApp

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- Design responsive avec media queries
- Google Fonts (Be Vietnam Pro, Slabo 27px)

## 🚀 Installation

1. Clonez le repository :
```bash
git clone https://github.com/juniorare-KING/Juniorare-KING.github.io.git
```

2. Ouvrez `connexion.html` dans votre navigateur

## 💻 Utilisation

1. **Connexion** : Accédez à la page d'accueil via `connexion.html`
2. **Navigation** : Utilisez le menu pour accéder aux différentes pages
3. **Produits** : Consultez les véhicules disponibles
4. **Contact** : Remplissez le formulaire ou contactez via WhatsApp
